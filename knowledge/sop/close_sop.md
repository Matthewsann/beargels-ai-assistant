# Close SOP

Version: 1.0 · Owner: Store Manager · Estimated Time: 60~90 minutes

## Purpose
영업 종료 후 매장을 다음 영업일과 동일한 상태로 준비한다.
깨끗한 매장, 정확한 재고, 안전한 시설을 유지하는 것이 목표.

## Scope
점장 · 마감 근무자 · 교육생(점장 감독 하)

## Success Criteria (마감 완료 조건)
모든 청소 완료 · 재고 정리 완료 · 식자재 보관 완료 · 장비 종료 완료 ·
POS 마감 완료 · 다음날 오픈 가능 상태

## Close Flow
① 고객 마무리 → ② 제조 종료 → ③ 재고 정리 → ④ 청소 → ⑤ POS 마감 →
⑥ 장비 OFF → ⑦ 최종 점검 → ⑧ 퇴근

## STEP 1. 고객 마무리
□ 마지막 주문 확인 □ 매장 고객 확인 □ 배달 주문 종료 확인 □ 고객 응대 마무리

## STEP 2. 제조 종료
□ 식재료 정리 □ 남은 재료 밀봉 □ 유통기한 확인 □ 냉장 보관 □ 폐기 대상 분리

## STEP 3. 재고 확인
□ 베이글 재고 확인 □ 샌드위치 재료 확인 □ 음료 재료 확인 □ 우유 확인
□ 시럽 확인 □ 소모품 확인 □ 발주 필요 품목 기록

## STEP 4. 청소
□ 테이블 □ 의자 □ POS □ 바닥 □ 싱크대 □ 제조대 □ 쇼케이스 □ 커피머신
□ 오븐 □ 화장실 □ 쓰레기 배출

## STEP 5. POS 마감
□ 일마감 □ 카드 매출 확인 □ 현금 확인 □ 영수증 확인 □ 이상 거래 확인

## STEP 6. 장비 종료
□ 커피머신 □ 그라인더 □ 오븐 □ 조명 □ 음악 □ 에어컨
> ⚠️ **냉장·냉동 설비는 종료하지 않는다.**

## STEP 7. 최종 점검
□ 출입문 잠금 □ 가스 확인 □ 전기 확인 □ 창문 확인 □ 냉장고 문 확인
□ 쇼케이스 확인 □ 매장 사진 촬영

## STEP 8. 보고
마감 완료 후 운영 채널에 보고:
특이사항 · 부족 재고 · 고장 사항 · 고객 컴플레인 · 다음 근무자 전달사항

## If Something Is Wrong
① 사진 촬영 → ② 점장 보고 → ③ 운영일지 기록 → ④ 임시 조치 → ⑤ 필요 시 대표 보고

## Do Not
- 식재료를 개봉 상태로 보관하지 않는다 · 청소를 다음 근무자에게 미루지 않는다 ·
  고장 사항을 보고하지 않는다 · POS 마감 없이 퇴근한다 · 냉장·냉동 설비를 끈다

## KPI
마감 완료 시간 · 청소 완료율 · 재고 정확도 · 인수인계 누락 건수 · 장비 이상 발견 건수
