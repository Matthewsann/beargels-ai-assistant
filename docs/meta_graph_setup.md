# 메타 그래프 API 붙이기 (사장님용)

Supermetrics 무료 체험이 2026-08-07에 만료돼서, **돈 안 드는 메타 공식 API**로
직접 붙였습니다. 아래는 **토큰 발급**만 하시면 되는 절차입니다.
코드는 이미 다 되어 있습니다.

## 이걸 붙이면 되는 것

| 기능 | 설명 |
|---|---|
| **해시태그 인기글 수집** | `#송도카페` `#과일산도` 등에서 잘 되는 게시물의 캡션·훅·좋아요 수집 → 기획 재료 |
| **내 계정 성과** | 게시물별 도달·저장·공유·좋아요 → 어떤 훅이 먹혔는지 측정 |

## 준비물 (이미 있음)

- 페이스북 페이지: **베어글스송도타임스페이스점** ✅
- 인스타 **프로페셔널(비즈니스) 계정** @beargels_songdo, 위 페이지와 연결됨 ✅

---

## 1단계 — 앱 만들기

1. https://developers.facebook.com/apps 접속 (본인 페이스북 계정으로 로그인)
2. **앱 만들기** 클릭
3. 사용 사례에서 **기타(Other)** → 앱 유형 **비즈니스(Business)** 선택
4. 앱 이름: `베어글스 SNS` (아무거나) → 만들기

## 2단계 — 토큰 발급

1. 왼쪽 메뉴 → **도구** → **그래프 API 탐색기**
   (또는 https://developers.facebook.com/tools/explorer)
2. 오른쪽 위 **Meta 앱**에서 방금 만든 앱 선택
3. **사용자 또는 페이지** → **사용자 토큰** 선택
4. **권한 추가**에서 아래를 체크합니다.

   **필수 4개 — 하나라도 빠지면 동작하지 않습니다:**
   ```
   pages_show_list
   pages_read_engagement
   business_management      ← 자주 빠뜨림
   instagram_basic
   ```
   **선택(있으면 좋음):**
   ```
   instagram_manage_insights   ← 목록에 없으면 건너뛰세요(다른 사용 사례 소속)
   ```

   > ⚠️ **`business_management` 를 꼭 넣으세요.** 베어글스 페이지는 비즈니스
   > 포트폴리오 소유라서, 이게 없으면 `pages_show_list` 가 있어도 페이지 목록이
   > **빈 배열**로 옵니다(에러도 안 뜹니다). 2026-08-30 실측으로 확인한 함정입니다.

   > ⚠️ 왼쪽 위 호스트가 **`graph.facebook.com`** 인지 확인하세요.
   > `graph.instagram.com` 으로 두면 페이지 권한이 목록에 아예 안 뜹니다.

5. **액세스 토큰 생성** 클릭 → 페이스북 로그인 창에서 **베어글스 페이지를 선택**하고 허용
6. 생성된 긴 문자열을 복사

## 3단계 — 장기 토큰으로 바꾸기 (권장)

2단계 토큰은 **1~2시간이면 만료**됩니다. 60일짜리로 바꾸세요.

1. https://developers.facebook.com/tools/debug/accesstoken 접속
2. 방금 복사한 토큰 붙여넣고 **디버그**
3. 아래쪽 **액세스 토큰 확장** 버튼 클릭
4. 새로 나온 토큰을 복사 (이게 진짜 쓸 토큰)

> 60일마다 갱신이 필요합니다. 만료되면 코드가 "토큰이 만료되었습니다"라고
> 알려주니 그때 이 단계만 다시 하시면 됩니다.

## 4단계 — .env 에 넣기

프로젝트 폴더의 `.env` 파일을 메모장으로 열고 맨 아래에 붙여넣습니다:

```
META_ACCESS_TOKEN=여기에_3단계에서_복사한_토큰
IG_USER_ID=
```

`IG_USER_ID`는 비워두면 자동으로 찾습니다.

## 5단계 — 확인

```bash
python check_meta.py
```

전부 `[O]` 로 나오면 끝입니다. 화면에 나온 `IG_USER_ID=...` 값을 `.env`에
넣어두면 다음부터 조금 더 빨라집니다.

## 6단계 — 시장 스캔 돌리기

```bash
python -m sns_automation.market_scan
```

`data/market_scan.json` 에 결과가 저장되고, 기획 에이전트가 자동으로 참고합니다.

## ⚠️ 알아둘 제약

- **해시태그 검색은 7일에 고유 30개까지.** 그래서 기본 해시태그를 5개로
  좁혀뒀고(`market_scan.DEFAULT_HASHTAGS`), 조회한 해시태그 ID는
  `data/hashtag_ids.json` 에 캐시합니다. **주 1회만 돌리세요.**
- **남의 게시물은 조회수·저장수를 주지 않습니다**(메타 정책). 좋아요·댓글만
  받을 수 있어서 인기 판정은 그걸로 합니다. 내 게시물은 도달·저장·공유 다 나옵니다.
- 해시태그당 인기 게시물은 최대 50개까지입니다.
