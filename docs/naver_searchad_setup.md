# 네이버 검색광고 API 발급 — 사장님용 안내

**목적은 광고가 아니라 데이터다.** 키워드의 **월간 검색수**를 받아 블로그 주제를
고르는 데 쓴다. 지금 시스템은 "이 말이 검색되나(있다/없다)"만 알고 "얼마나
검색되나"를 모른다. 그래서 월 10회짜리와 월 3,000회짜리가 똑같이 "지금 쓰면
이긴다"로 추천된다(시장조사 검토 2026-09-04).

걸리는 시간 **10~15분**. 광고를 켜지 않으면 **돈은 나가지 않는다.**

---

## 0. 시작 전에 — 이것만 지키면 돈 안 나간다

| 하지 말 것 | 이유 |
|---|---|
| 캠페인·광고그룹 만들기 | 캠페인이 켜져 있으면 광고가 나가고 비즈머니가 빠진다 |
| 자동충전(자동결제) 켜기 | 잔액이 떨어지면 카드에서 자동으로 결제된다 |
| "최대 50만원 광고비 혜택" 따라가기 | 가입 화면의 광고 유도 문구다. 우리 목적은 데이터뿐 |
| 직원 아이디로 가입 | 나중에 계정을 넘길 방법이 없다(네이버 공식 경고) |

**반드시 사장님(대표자) 본인 네이버 아이디로** 가입한다.

---

## 1. 광고주 가입 (5분)

1. https://ads.naver.com/signup 을 연다.
   - 예전 주소(searchad.naver.com, saedu.naver.com)는 여기로 넘어온다.
2. **[네이버 ID로 광고 시작하기]** 를 누른다. 별도 계정을 만드는 게 아니라
   쓰던 네이버 아이디로 붙는다.
3. 네이버 로그인 → 약관 동의 → 상세정보 입력 → 휴대폰 본인인증.
   - 여기까지가 **회원 가입**이다.
4. **광고 계정 생성** 화면에서 광고주 유형을 고른다.
   - **[사업자 광고주]** 를 권한다. 사업자등록번호를 넣는다. 베어글스는
     사업자가 있고, 나중에 플레이스광고나 세금계산서를 볼 여지가 있다.
   - 데이터만 볼 거면 [개인 광고주]가 입력이 더 적다. 차이는 몇 분이다.
5. 상세정보 입력 → **광고 계정 생성 완료**.

> 회원가입까지만 하고 멈추는 것도 가능하지만, **광고 계정이 있어야 도구와 API를
> 쓸 수 있다**(네이버 공식). 4~5단계까지 끝내야 한다.

---

## 2. 키워드 도구로 먼저 눈으로 확인 (2분, 선택)

**[검색광고 > 도구 > 키워드 도구]** 에서 "송도 베이글 산도" 같은 말을 쳐 본다.
연관키워드, 월간검색수(PC·모바일), 경쟁정도가 표로 나온다. 여기서 숫자가
보이면 API로도 같은 값을 받을 수 있다.

- 10 미만 검색수는 숫자 대신 `< 10` 으로 나온다.
- 이 도구는 **파워링크 캠페인 유형에 한해** 지원된다(공식). 화면이 안 열려도
  API는 될 수 있으니 3번으로 넘어가면 된다.

---

## 3. API 키 발급 (3분)

1. **[검색광고 > 도구 > SA API 사용 관리]** 로 들어간다.
   - 화면이 예전 것이면 [광고시스템] → `manage.searchad.naver.com` →
     [도구 > API 사용 관리] 경로다.
2. **[네이버 검색광고 API 서비스 신청]** 을 누른다.
3. 약관을 읽고 **[위 내용을 모두 읽고 확인했습니다]** 체크 → **[저장하기]**.
4. **액세스라이선스**와 **비밀키**가 자동으로 발급된다.
5. **고객 ID(CUSTOMER_ID)** 를 함께 확인한다. 같은 화면이나 로그인 후 오른쪽 위
   내 정보에 있는 숫자다.

> 네이버 공식: "네이버 검색광고 회원(광고주 혹은 파트너사)이면 **누구나** API
> 서비스를 사용할 수 있습니다."

---

## 4. 값 세 개를 집 PC에 넣기

집 PC 리포의 `.env` 파일을 열어 아래 세 줄을 채운다.

```
NAVER_AD_API_KEY=액세스라이선스
NAVER_AD_SECRET_KEY=비밀키
NAVER_AD_CUSTOMER_ID=고객ID숫자
```

- `.env` 는 GitHub에 안 올라간다(`.gitignore`에 이미 있음).
- **비밀키를 카톡·메일·메모장에 붙여넣지 말 것.** 비밀번호와 같다.
- 유출되면 같은 화면에서 **비밀키만 재발급**하면 된다.
  (액세스라이선스는 API 서비스 탈퇴 후 재가입해야 다시 나온다.)

---

## 5. 알아둘 것

- **비용**: 키워드도구 API의 요금표는 공식 문서 어디에도 없다. 비즈머니는
  "광고를 집행하는 데 쓰는 충전금"으로만 정의돼 있다. 즉 **광고를 켜지 않으면
  돈이 나갈 자리가 없다.** 다만 "잔액 0원 계정에서도 이 API가 응답한다"고
  못 박은 공식 문장은 찾지 못했다 — 키를 받아 한 번 호출해 보면 바로 안다.
- **호출 제한이 빡빡하다**: 키워드도구는 다른 기능보다 호출 속도가 1/5~1/6로
  제한된다(공식). 우리는 주 1회 몇 번만 부르므로 문제 없다.
- **한 번에 5개까지**: 키워드는 요청당 최대 5개씩 넣을 수 있다.
- **2026-07-02 공지**: 검색광고 계정 통합 이후 일부 계정의 비밀키가 바뀐 사례가
  있다. 나중에 인증 오류가 나면 이 화면에서 키를 다시 확인하거나 재발급한다.

---

## 6. 다 되면

세 값을 `.env` 에 넣었다고 알려주시면, 검색량을 판정 규칙에 넣는 작업을
이어서 한다. 지금 규칙은 경쟁이 적은 순으로만 줄을 세워서, 아무도 안 찾는
말을 1등으로 밀어올릴 수 있다. 검색량이 들어오면 그게 막힌다.

키가 없어도 시스템은 지금처럼 돈다 — 검색량만 빠진 채로 동작한다.
