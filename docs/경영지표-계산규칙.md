## 영업이익

```
영업이익 = 정산총액 − 매입원가 − 고정비
```

**정산총액**은 카드·배달 수수료가 이미 차감된 실입금액이다.
매출총액에서 수수료를 따로 빼면 **이중 차감**된다.

검산 (2026-07): `25,659,250 − 14,088,280 − 11,843,549 = −272,579` ✅

## 장부 열 매핑

`베어글스_장부_26_07.xlsx` 요약시트 기준
`C5=10월, C6=11월 … C14=7월, C15=8월(예상치)`

⚠️ C15는 실적이 아니라 예상치다. 실적으로 쓰면 안 된다.

## 변동비 / 고정비

| 변동비 (매출 비례) | 고정비 (매출 무관) |
|---|---|
| 식자재, 배달 수수료, 카드 수수료 | 인건비, 임대료, 기타 |

```
공헌이익률 = 100% − 변동비율
손익분기 매출 = 고정비 ÷ 공헌이익률
```

2026-07: 고정비 1,184만 ÷ 34.6% = **3,597만원**

## 배달 수수료

```
기본 수수료 = 매출 × (중개율 + 결제 3.0%) × 1.1   ← 부가세 포함
```
- 중개율: 상생요금제 2.0~7.8% 구간별 차등 (베어글스 상위구간 7.8%)
- 나머지는 광고비 + 배달비 매장부담
- 업계 실질 부담 평균 **25~30%**, 베어글스 **38%대**

## 목표치

| 지표 | 목표 |
|---|---|
| 원가율 | ≤ 35% |
| 인건비율 | ≤ 20% |
| 영업이익률 | ≥ 10% |
| 월 매출 | 4,000만원 |

## 데이터 처리 주의

- **허수 제외**: 매입사가 `직원식대`, `폐기`인 건
- **단체주문**: 20만원 이상, 별도 집계
- POS 파일 `결제 상세내역` 시트, `결제상태=='승인'` 필터
- 장부와 POS는 소폭 차이 있음 → **장부가 확정값**
