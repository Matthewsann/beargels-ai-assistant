## 1. 붙이는 방법

기존 `guide` 라우트와 동일한 패턴. DB·패키지 추가 없음.

### 1-1. `service/app.py` — 라우트 추가

```python
@app.route("/<path_key>/analytics")
def analytics(path_key):
    """경영 대시보드 — 매출·비용·상품·운영 (정적 페이지, DB 안 씀)."""
    check(path_key)
    return render_template("analytics.html", key=path_key)
```

### 1-2. `service/templates/_sidebar.html` — 메뉴 추가

섹션 판정에 `analytics` 추가:
```jinja
{% set _sec = 'analytics' if '/analytics' in _p else ('menu' if '/menu' in _p else (...)) %}
```

메뉴 항목 (리뷰 답글 위, 최상단):
```jinja
<a class="sm {{ 'on' if _sec == 'analytics' else '' }}" href="/{{ key }}/analytics">📊 경영 대시보드</a>
```

### 1-3. `service/templates/analytics.html` — 신규

- 완전한 HTML 문서 (`<!doctype html>` 포함)
- `<body>` 직후 `{% include "_sidebar.html" %}`
- `<head>`에 `<meta name="robots" content="noindex, nofollow">`
- 사이드바가 `body{padding-left:198px}`를 넣으므로 본문 좌우 패딩은 `.wrap`에서 처리
- Chart.js CDN 사용: `https://cdnjs.cloudflare.com/ajax/libs/Chart.js/4.4.1/chart.umd.js`

## 2. ⚠️ 영업이익 산식 — 가장 중요

장부(`베어글스_장부_26_07.xlsx` 요약시트)의 실제 산식:

```
영업이익 = 정산총액 − 매입원가 − 고정비
```

**정산총액**은 카드·배달 수수료가 **이미 차감된 실입금액**이다.

### 검산 (2026년 7월)
```
25,659,250 − 14,088,280 − 11,843,549 = −272,579원  ✅ 장부값과 소수점까지 일치
```

### 하면 안 되는 계산
```
❌ 매출총액 − 원가 − 고정비 − 배달수수료 − 가게배달비
   → 가게배달비 이중 차감 + 매장 카드수수료 누락으로 28만원 어긋남
```

### 매출총액 ↔ 정산총액 차액 검증
```
33,399,713 − 25,659,250 = 7,740,463
  ├ 배달 수수료&광고  7,448,667
  └ 매장 카드수수료     291,796  (= 매장매출 13,895,026 × 2.1%)
```

**주의**: 장부 요약시트에서 7월은 **C14 열**이다. C15는 8월 예상치이므로 혼동 금지.

## 5. 배달 수수료 구조

### 5-1. 분해 (2026 상생요금제 기준)

| | 배달의민족 | 쿠팡이츠 |
|---|---|---|
| 매출 | 1,002만 (560건) | 861만 (479건) |
| 기본 수수료 | 119만 · **11.9%** | 102만 · **11.8%** |
| 광고비+배달비 | 264만 · **26.3%** | 228만 · **26.5%** |
| **실질 수수료율** | **38.2%** | **38.4%** |

**기본 수수료 = 중개 7.8% + 결제 3.0%, 부가세 포함**
→ `매출 × (0.078 + 0.030) × 1.1 = 11.88%`

중개수수료는 매출 구간별 2.0~7.8% 차등(상생요금제). 베어글스는 상위 구간이라 7.8%.

### 5-2. 업계 비교
실질 부담 업계 평균 **25~30%** → 베어글스 38%대는 **8~13%p 높음**.
기본 수수료는 정상, **광고비가 과다**한 구조.

### 5-3. 계산기 사양

입력
- 월 배달 매출 (기본 1950만)
- 가게배달 건수 (기본 82건, 바로고 대행분만)
- 중개 수수료율 슬라이더 2.0~9.8% (기본 7.8%)
- 광고비+배달비 부담률 슬라이더 5~35% (기본 27.7%)
- 배달대행 건당 3,000~5,000원 (기본 3,800원)

계산
```js
기본   = 매출 × (중개% + 3.0) / 100 × 1.1
광고   = 매출 × 광고% / 100
대행   = 건수 × 건당 / 10000
총수수료 = 기본 + 광고 + 대행
실수익  = 매출 − 총수수료
```

**검산**: 기본값 → 232 + 540 + 31 = **802만** (7월 실적과 일치), 수수료율 41.2%
