## 에이전트 분류 (7개)

### 0. 오케스트레이터 — 웹 파이프라인 ✅ 완성
- **역할:** 전체 흐름 지휘. 사장님이 브라우저에서 6단계를 클릭으로 진행.
- **코드:** `sns_automation/webapp.py`, `web/pipeline.html`, `run_web.py`
- **실행:** PC에서 `5_웹파이프라인.bat`
- **입출력:** 프로젝트(주제) 생성 → 각 에이전트 호출 → 결과를 화면에 표시.

### 1. 자료 수집 에이전트 (Collector) ✅ 완성
- **역할:** 구글 드라이브 "콘텐츠 생성" 하위 주제폴더 목록 조회·검색, 영상/사진 다운로드. 웹에서 파일 직접 업로드도 지원.
- **코드:** `sns_automation/drive_monitor.py` (OAuth 로그인, `3_google_login.bat`)
- **입력:** 폴더명(주제) / **출력:** 원본 클립 파일들

### 2. 기획 에이전트 (Planner) 🔶 부분 구현
- **역할:** 콘텐츠 기둥 6개·성장전략에 맞춰 "이 소재는 어떤 템플릿(T1~T5)·길이·훅으로 만들지" 결정.
- **코드:** `sns_automation/templates.py` + `knowledge/growth_strategy.md`, `knowledge/reel_templates.md`
- **현재:** 템플릿 5종 정의됨. 단, **자동 선택은 미구현 — T1 고정**. (다음 개발 1순위)
- **입력:** 주제·클립 정보 / **출력:** 템플릿 선택 + 훅/자막 방향

### 3. 영상 편집 에이전트 (Editor) ✅ 완성 (테스트 통과)
- **역할:** 클립들 → 9:16(1080×1920) 릴스. 회전 보정, 이어붙이기, 훅 자막(첫 2.5초)·메뉴 자막, 원본 ASMR 소리 + 배경음악 믹스, 길이 컷.
- **코드:** `sns_automation/video_editor.py` (ffmpeg 내장 — 별도 설치 불필요)
- **입력:** 클립 + 템플릿 + 문구 / **출력:** 릴스 mp4

### 4. 카피라이터 에이전트 (Copywriter) ✅ 완성
- **역할:** 영상/사진을 보고 브랜드 보이스("꾸밈없이 맛있는 것만")로 캡션 작성. 첫 줄 훅 + 송도 로컬 SEO 키워드 + 해시태그 3~5개 + 저장/공유 CTA.
- **코드:** `sns_automation/caption_generator.py` — `knowledge/` 전체(매장정보·전략)를 항상 참고.
- **입력:** 미디어 + 주제 / **출력:** 캡션·해시태그·오버레이 문구 (웹에서 직접 수정 가능)

### 5. 발행 에이전트 (Publisher) 🔶 반자동 (전략적 결정)
- **역할:** 완성본 mp4 + 캡션을 지정 폴더(또는 드라이브)에 저장 → **사장님이 인스타/Meta Edits 앱에서 인기 음원 얹어 발행**.
- **이유:** 인기 음원은 공식 API로 못 붙임. 외부 음악 삽입 시 도달 ~25%↓ → 반자동이 도달에 최적 (growth_strategy.md ⭐ 결정).
- **코드:** `webapp.py` finalize(완성본 저장) + 보조용 `buffer_client.py`(평범한 클립 자동발행 시)

### 6. 분석 에이전트 (Analyst) ⏸ 보류
- **역할(계획):** 인사이트(도달·저장·공유) 수집 → 잘 된 포맷 파악 → 기획 에이전트에 피드백 루프.
- **현재:** 페북 계정 문제로 자동 연동 보류. 당분간 인사이트 스크린샷을 주면 수동 분석.

## 데이터 흐름 (한 번의 릴스 제작)

1. 수집A: 주제폴더에서 클립 다운로드
2. 기획A: 템플릿·길이·훅 결정 *(현재는 T1 고정 + 사장님이 웹에서 훅/메뉴 입력)*
3. 편집A: 릴스 mp4 렌더링
4. 카피A: 캡션·해시태그 생성
5. 검수: 사장님이 웹에서 미리보기·수정·승인
6. 발행A: 완성본 저장 → Edits 앱에서 인기음원 + 발행

## 2026-08-11 보강 — "양끝" 4가지 (업계 리서치 반영, `planner.py`)

리서치 결과 제작 엔진(가운데)은 업계 수준이었으나 앞단·뒷단이 비어 있어 보강:

1. **주간 촬영 체크리스트** (기획A 확장) — `🤖 새로 계획 짜기` 버튼. AI가 지침 +
   훅 성과 기록 + 인사이트 분석을 근거로 이번 주 찍을 릴스 3개(가이드·훅·발행요일)
   생성. 크레딧 없으면 기본 풀 8개 순환. 항목에서 바로 프로젝트 시작.
2. **훅 3버전 추천** (1→N 변형) — `🎣 훅 3버전 추천` 버튼. 같은 소재로 각도가 다른
   훅 3개(호기심/구체성/지역·한정). 완성본 저장은 덮어쓰지 않고 `reel_2.mp4`처럼
   버전 추가 → 훅 A/B 테스트 가능.
3. **발행 대기 큐** — 완성된 릴스 목록 + 발행 리듬 안내(월·수·금, 러시 30분 전) +
   `📋 캡션 복사`(Edits 앱 붙여넣기용) + `✅ 발행 완료` 기록.
4. **주간 리뷰 (성과 피드백 루프)** — 발행한 릴스마다 도달/저장/공유/좋아요 입력
   (훅 라이브러리, `data/hook_library.json`) + 인사이트 스크린샷 AI 분석
   (`data/insights_log.json`). 둘 다 다음 주간 계획 프롬프트에 자동 반영.

`data/` 폴더는 기기 로컬(gitignore) — 성과 기록은 집 PC에 쌓인다.
