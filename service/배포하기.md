# 직원용 리뷰 답글 서비스 — 인터넷 배포하기 (PythonAnywhere)

한 번만 하면 됩니다. 15분쯤 걸립니다.

배포 후 모습:
```
https://<사용자명>.pythonanywhere.com/<비밀주소>/
```
이 주소를 직원 단톡방에 공유하면 끝입니다. 로그인 화면은 없고, **주소를 아는
사람만** 들어올 수 있습니다.

---

## 1단계 — 계정 만들기

https://www.pythonanywhere.com/registration/register/beginner/ 에서
**Create a Beginner account**(무료, 카드 필요 없음).

- 사용자명은 주소가 됩니다. `beargels` 같은 걸로 정하세요.
- 가입 후 이메일 인증까지 마칩니다.

---

## 2단계 — 코드 내려받기

위쪽 메뉴 **Consoles** → **Bash** 를 눌러 검은 창을 엽니다. 아래를 붙여넣고 엔터:

```bash
git clone https://github.com/Matthewsann/beargels-ai-assistant.git
pip3 install --user -r beargels-ai-assistant/service/requirements.txt
```

(2~3분 걸립니다. 글자가 주르륵 올라가면 정상입니다.)

---

## 3단계 — 설정 파일 올리기

위쪽 메뉴 **Files** → `beargels-ai-assistant/service/` 폴더로 들어갑니다.

**Upload a file** 을 눌러 집 PC 의 이 파일을 올립니다:

```
C:\Users\명구\Claude\beargels-ai-assistant\service\.env.production
```

올린 뒤 파일 이름 옆 연필(✏️) 대신, 같은 폴더에서 **이름을 `.env` 로** 바꿔야
합니다. 이름 바꾸기가 안 보이면 Bash 창에서 아래 한 줄이면 됩니다:

```bash
mv ~/beargels-ai-assistant/service/.env.production ~/beargels-ai-assistant/service/.env
```

> 이 파일에는 Supabase 접속 정보와 비밀 주소만 들어 있습니다.
> 배민·쿠팡 비밀번호, 텔레그램 토큰, AI 키는 **들어 있지 않습니다**(집 PC 전용).

---

## 4단계 — 웹앱 만들기

위쪽 메뉴 **Web** → **Add a new web app** →
**Manual configuration** → **Python 3.10**(또는 목록 중 가장 높은 3.x).

만들어지면 그 페이지에서 두 군데만 고칩니다.

**(1) Source code** 칸:
```
/home/<사용자명>/beargels-ai-assistant/service
```

**(2) WSGI configuration file** 링크를 눌러 편집기가 열리면, **안에 있는 내용을
전부 지우고** 아래로 바꿉니다 (`<사용자명>` 두 곳을 본인 것으로):

```python
import sys

path = '/home/<사용자명>/beargels-ai-assistant/service'
if path not in sys.path:
    sys.path.insert(0, path)

from wsgi import application
```

**Save** 를 누르고 Web 페이지로 돌아와 초록색 **Reload** 버튼을 누릅니다.

---

## 5단계 — 열어보기

```
https://<사용자명>.pythonanywhere.com/<비밀주소>/
```

비밀주소는 3단계에서 올린 `.env` 안의 `SERVICE_PATH` 값입니다.

- 화면이 뜨면 성공입니다. 이 주소를 직원분들께 공유하세요.
- 주소 뒤 비밀주소를 빼면 **404** 가 뜹니다(정상 — 아무나 못 들어옵니다).

---

## 앞으로

**코드를 고친 뒤 반영하려면** Bash 창에서:

```bash
cd ~/beargels-ai-assistant && git pull
```
그다음 **Web** 탭의 **Reload** 버튼.

**직원이 [리뷰수집]을 누르면** 집 PC 일꾼이 대신 긁어옵니다. 그래서 집 PC 에서
아래 두 개가 켜져 있어야 합니다:

1. `scripts\launch_chrome.bat` — 배민·쿠팡 로그인된 Chrome
2. `worker\run_agent.bat` — 일꾼

둘 다 꺼져 있으면 직원 화면에 "집 PC가 꺼져 있어요"라고 표시되고, 이미 만들어둔
답글 초안은 그대로 쓸 수 있습니다.

**무료 계정 유지**: 3개월에 한 번 PythonAnywhere 가 "아직 쓰고 있나요?" 메일을
보냅니다. Web 탭에서 버튼 한 번 누르면 계속 유지됩니다.
