# 밖에서 쓰기 (다른 컴퓨터·휴대폰에서 접속)

리뷰 답글 만들기를 집 PC 앞이 아니어도 쓰기 위한 설명입니다.
**고정 주소 방식(권장)** 과 **임시 주소 방식** 두 가지가 있습니다.

---

## A. 고정 주소 방식 (권장 · 무료 · 도메인 불필요)

주소가 한 번 정해지면 계속 그대로입니다. 즐겨찾기에 넣고 쓰면 됩니다.
Tailscale 이라는 사설망을 씁니다 — 인터넷에 공개되지 않고, 내 계정으로
로그인한 기기끼리만 연결돼서 가장 안전합니다.

### 집 PC (한 번만)

1. 설치 — 명령 프롬프트에서:
   ```
   winget install --id tailscale.tailscale
   ```
2. `webapp\setup_fixed_address.bat` 더블클릭. 순서대로 물어봅니다:
   - 브라우저가 열리면 구글 계정으로 로그인
   - 웹앱 비밀번호를 물어보면 하나 정하기
   - "PC 켜면 자동 시작?" 에 `y` → 앞으로 PC만 켜져 있으면 비서가 항상 켜져 있음
     (끄고 싶으면 작업 스케줄러에서 `BeargelsAssistant` 삭제)
3. 마지막에 나오는 주소를 적어두세요. 이런 모양입니다:
   ```
   https://내PC이름.무슨무슨.ts.net
   ```

### 휴대폰·노트북 (기기마다 한 번만)

1. Tailscale 앱 설치 (앱스토어/플레이스토어, 또는 위 winget 명령)
2. **집 PC와 같은 구글 계정**으로 로그인
3. 위 `https://...ts.net` 주소를 브라우저에 입력 → 비밀번호 입력 → 끝

> 처음에 "MagicDNS / HTTPS 를 켜라"는 안내가 나오면
> https://login.tailscale.com/admin/dns 에서 두 개를 켜고 2번을 다시 실행하세요.

### 알아둘 점

- **집 PC가 켜져 있어야** 접속됩니다. (PC가 꺼져 있으면 안 열림)
- 쓸 기기에 Tailscale 앱이 깔려 있어야 합니다. 처음 한 번만 하면 됩니다.
- 주소는 다시 바뀌지 않습니다.

---

## B. 임시 주소 방식 (앱 설치 없이 급할 때)

접속할 기기에 아무것도 안 깔아도 됩니다. 대신 **주소가 켤 때마다 바뀝니다.**

1. 집 PC에 한 번만: `winget install --id Cloudflare.cloudflared`
2. 쓸 때마다 `webapp\start_public.bat` 더블클릭
3. 창에 나오는 `https://무슨무슨.trycloudflare.com` 주소를 복사해 다른 기기에 입력

- 이 주소는 **인터넷에 공개**됩니다. 비밀번호는 반드시 있어야 하고, 주소를
  아무에게나 공유하지 마세요.
- 창을 닫으면 즉시 끊깁니다.

---

## C. 같은 집 와이파이 안에서만

`run.bat` 만 켜고 다른 기기에서 `http://집PC주소:5050` 으로 접속하면 됩니다.
(집 PC 주소는 명령 프롬프트에 `ipconfig` 를 치면 나오는 IPv4 주소)

## 리뷰 답글 화면이 하는 일

- 리뷰 내용·별점·메뉴를 넣으면 **답글 초안**을 만들어 줍니다. 복사해서 배민/쿠팡에
  직접 붙여넣으세요. (웹에서 자동 게시는 하지 않습니다 — 안전장치)
- 이물질·환불·법적 언급 등 **민감 리뷰는 답글을 만들지 않고** 직접 대응하라고
  알려줍니다.
- 답글 톤은 텔레그램 봇과 똑같은 생성기(`assistant/beargels.py`)를 씁니다.
- ⚠️ AI 크레딧이 없으면 정해진 문장(템플릿) 답글이 나옵니다. 진짜 AI 답글은
  console.anthropic.com 에서 크레딧을 채운 뒤부터 나옵니다.
