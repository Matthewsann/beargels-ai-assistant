# 밖에서 쓰기 (다른 컴퓨터·휴대폰에서 접속)

리뷰 답글 만들기를 집 PC 앞이 아니어도 쓰기 위한 설명입니다.

## 준비 (딱 한 번만)

1. 터널 프로그램 설치 — 명령 프롬프트에서 한 번:
   ```
   winget install --id Cloudflare.cloudflared
   ```
2. 끝. 비밀번호는 처음 실행할 때 물어봅니다.

## 쓸 때마다

1. 집 PC에서 `webapp\start_public.bat` 더블클릭.
2. 창에 나오는 주소를 복사 → 휴대폰/다른 컴퓨터 브라우저에 붙여넣기.
   ```
   https://무슨무슨-단어들.trycloudflare.com
   ```
3. 비밀번호 입력 → 💬 리뷰 답글 탭에서 사용.

## 알아둘 점

- **주소는 켤 때마다 바뀝니다.** 매번 새로 복사해야 해요.
  (고정 주소가 필요해지면 도메인을 연결하는 방식으로 바꿀 수 있습니다.)
- **집 PC가 켜져 있고 이 창이 열려 있어야** 밖에서 접속됩니다. 창을 닫으면 끊깁니다.
- 인터넷에 열리는 주소이므로 **비밀번호는 반드시** 있어야 하고, 주소를 아무에게나
  공유하지 마세요.
- 같은 집 와이파이 안에서만 쓸 거면 터널 없이 `run.bat` 만 켜고
  `http://집PC주소:5050` 으로 접속해도 됩니다.

## 리뷰 답글 화면이 하는 일

- 리뷰 내용·별점·메뉴를 넣으면 **답글 초안**을 만들어 줍니다. 복사해서 배민/쿠팡에
  직접 붙여넣으세요. (웹에서 자동 게시는 하지 않습니다 — 안전장치)
- 이물질·환불·법적 언급 등 **민감 리뷰는 답글을 만들지 않고** 직접 대응하라고
  알려줍니다.
- 답글 톤은 텔레그램 봇과 똑같은 생성기(`assistant/beargels.py`)를 씁니다.
- ⚠️ AI 크레딧이 없으면 정해진 문장(템플릿) 답글이 나옵니다. 진짜 AI 답글은
  console.anthropic.com 에서 크레딧을 채운 뒤부터 나옵니다.
