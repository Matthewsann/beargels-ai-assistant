사용법

버튼 세 번이면 릴스가 나와요

1
폰으로 찍어서 드라이브에 올리기

갤러리 → 공유 → 드라이브 → 콘텐츠 생성 / 원본소재 / (주제 폴더). 주제 폴더 안에 촬영가이드 파일이 있으면 그대로 찍으면 돼요. 새 주제는 드라이브에서 폴더만 새로 만들면 됩니다.

잘 찍혔는지 고르지 말고 찍은 걸 다 올리세요. 고르는 건 편집이 합니다.

2
이 화면 «소재 창고»에서 시작

올린 폴더가 카드로 뜹니다(최대 15초). [🎬 이 소재로 릴스 시작] 을 누르면 원본을 복사하지 않고 그대로 연결돼요.

3
샷 구성표 확인 → «✨ AI가 자막 쓰기»

어떤 장면을 몇 초, 어떤 자막으로 쓸지가 표로 나옵니다. AI가 장면을 보고 사장님 말투로 자막을 써줘요(1회 약 150원). 마음에 안 드는 줄만 고치면 됩니다.

기본 순서는 훅 → 과정 → 디테일 → 자르는 순간 → 단면 공개 → 마무리. «자르는 순간»만 원본 소리가 남습니다(칼 소리).

4
«🎬 릴스 만들기» → 확인 → 완성본 저장

구성표대로 편집됩니다(1~2분). 미리보기로 확인하고 캡션을 다듬은 뒤 [📁 완성본 폴더에 저장].

5
인스타 앱에서 발행 (사람이 직접)

완성본은 무음이에요. Meta Edits 앱에서 인기 음원을 얹어 올리세요. 인기 음원은 앱에서만 붙일 수 있고, 도달에 가장 크게 영향을 줍니다.

발행 후 «발행 대기»에서 [✅ 발행 완료]를 눌러주세요. 그래야 성과 기록이 시작돼요.

6
2~3일 뒤 성과 숫자 적어두기

인스타 인사이트의 도달·저장·공유를 «주간 리뷰»에 입력하면, 다음 기획 때 AI가 잘 됐던 훅을 변형해 재활용합니다. 이게 쌓일수록 결과물이 좋아져요.

막힐 때 · 창고에 폴더가 안 보이면 → 드라이브 동기화가 끝났는지 확인(폰 업로드 직후엔 몇 분 걸릴 수 있어요). 영상 없이 사진만 있으면 릴스를 만들 수 없어요. 편집이 실패하면 영상 파일이 너무 짧지 않은지 보세요(1초 이상 필요).
이번 주

촬영 체크리스트

반나절에 몰아서 찍고(배치 촬영), 요일별로 나눠 발행하는 게 물량의 비결이에요. 성과를 기록할수록 AI 계획이 똑똑해져요.

소재 창고 · 드라이브 "원본소재"

폰에서 올린 촬영본 — 폴더가 곧 릴스 주제예요

폰 갤러리 → 공유 → 드라이브 → 원본소재/(주제) 폴더에 올리면 여기 자동으로 떠요. 새 주제는 드라이브에서 폴더만 만들면 됩니다.
