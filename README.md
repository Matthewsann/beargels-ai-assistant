# 🐻 베어글스 AI 블로그 운영 키트

베어글스 베이커리 카페의 **네이버 블로그 운영을 AI로 반자동화**하는 키트입니다.
"무슨 글을 쓸지 고민 → 글쓰기 → 발행"의 앞 두 단계를 AI가 대신하고,
사장님은 **최종 확인과 발행만** 하면 됩니다.

---

## 🎯 이 키트가 해결하는 것

| 고민 | 해결 방법 |
|------|-----------|
| 꾸준히 못 올림 | `콘텐츠-캘린더.md` — 한 달 발행 계획이 미리 짜여 있음 |
| 무슨 글 쓸지 모름 | `프롬프트/` — 글 유형별로 소재까지 AI가 뽑아줌 |
| 글쓰기가 오래 걸림 | 프롬프트 하나 실행 → 붙여넣을 초안 완성 |
| 검색 노출이 안 됨 | `SEO-체크리스트.md` — 네이버 상위 노출 규칙 반영 |
| 톤이 매번 다름 | `브랜드-가이드.md` — 베어글스 목소리 고정 |

---

## 🚀 매주 이렇게 쓰세요 (3단계 · 약 15분)

1. **`콘텐츠-캘린더.md`** 를 열어 이번 주에 올릴 글 주제를 확인합니다.
2. 해당 글 유형의 **`프롬프트/` 파일**을 복사해서 AI(Claude·ChatGPT 등)에게 붙여넣고,
   `[대괄호]` 부분만 이번 주 상황(신메뉴 이름, 이벤트 내용 등)으로 바꿔 실행합니다.
3. 나온 초안을 **`SEO-체크리스트.md`** 로 30초간 점검하고, 네이버 블로그에 붙여넣어 발행합니다.

> 사진은 매장에서 찍은 실물 사진을 쓰는 게 검색 노출·신뢰도에 가장 좋습니다.
> AI 이미지는 배경/썸네일 보조용으로만 사용하세요. (자세한 건 `운영-가이드.md`)

---

## 📁 폴더 구조

```
README.md              ← 지금 이 문서 (전체 사용법)
브랜드-가이드.md        ← 베어글스 톤·핵심 정보 (한 번만 채우면 끝)
콘텐츠-캘린더.md        ← 4주 발행 계획표
SEO-체크리스트.md       ← 발행 전 30초 점검표
운영-가이드.md          ← 사진·발행 시간·응대 등 실전 팁
프롬프트/               ← 글 유형별 AI 프롬프트 (핵심)
   ├─ 01-신메뉴-소개.md
   ├─ 02-이벤트-홍보.md
   ├─ 03-일상-비하인드.md
   ├─ 04-고객후기-재구성.md
   └─ 05-정보성-베이글상식.md
예시글/                 ← 그대로 참고할 수 있는 완성 샘플
   ├─ 예시-소금빵-신메뉴.md
   └─ 예시-여름음료-이벤트.md
```

---

## ✅ 처음 한 번만 하면 되는 준비

1. **`브랜드-가이드.md`** 를 열어 `[대괄호]` 부분(매장 주소, 영업시간, 대표 메뉴 등)을
   실제 정보로 바꿔주세요. 이게 모든 글의 기준이 됩니다.
2. 나머지는 그대로 두고 매주 위 3단계만 반복하면 됩니다.
