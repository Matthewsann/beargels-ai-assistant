# 🐻 브랜드 자산 폴더

썸네일/포스터 생성기(`make_thumbnail.py`)가 이 폴더의 파일을 자동으로 사용합니다.

## 포함된 파일
- `color_palette.png` ✅ — 공식 컬러 팔레트 (크림 #FAF3E1 / 베이지 #F5E7C6 / 오렌지 #FA8112 / 블랙 #222222)
  → 코드에 이미 반영되어 있어 그대로 두면 됩니다.

## PC에서 한 번만 받아 넣을 파일 (구글드라이브 → 이 폴더)

구글드라이브 `베어글스_브랜드_이미지관련` 폴더에서 아래 파일을 내려받아 **이 폴더에 저장**하세요:

| 파일명 (정확히 이 이름으로 저장) | 드라이브 원본 | 용도 |
|--------------------------------|--------------|------|
| `bi_beargri.png` | bi_beargri.png | 썸네일에 베어그리 캐릭터 자동 삽입 (없으면 그린 곰 폴백) |
| `logo.png` (선택) | 베어글스로고_정사각.jpeg | 향후 워터마크 등 |
| `typo.png` (선택) | 타이포_베어글스송도.png | 향후 헤더 등 |

드라이브 바로가기: https://drive.google.com/drive/folders/127RxUa2FZ1ADgZyPzuccl6xsZL0fXTKQ

> `bi_beargri.png` 를 넣은 뒤 `py src\make_thumbnail.py "테스트"` 를 실행하면
> 진짜 베어그리가 들어간 썸네일이 나옵니다.
