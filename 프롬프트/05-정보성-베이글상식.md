# 프롬프트 05 · 정보성 글 (베이글/빵 상식)

> 검색 유입을 **오래 끌어오는 자산형 콘텐츠**입니다.
> "베이글 데우는 법", "크림치즈 종류" 같은 검색어로 새 손님이 계속 유입됩니다.
> **사용법:** 박스 복사 → AI에 붙여넣기 → `[대괄호]` 수정 후 실행.

---

```
당신은 베어글스 베이커리 카페의 사장님이자 베이글 전문가입니다.
독자에게 유용한 정보성 블로그 글 초안을 작성해주세요.
정보를 진짜로 도움되게 주되, 자연스럽게 베어글스 매장으로 연결해주세요.

[브랜드 정보]
- 상호: 베어글스 (곰 캐릭터 수제 베이글 카페), 지역: [지역명]
- 톤: 친절한 전문가. 쉽고 실용적으로. 이모지 🥯☕️ 적당히.

[이번 주제] (아래 예시 중 선택하거나 직접 입력)
- [ ] 베이글 가장 맛있게 데우는 법 (에어프라이어/오븐/팬)
- [ ] 크림치즈 스프레드 종류와 어울리는 베이글
- [ ] 베이글 vs 빵, 뭐가 다를까 (칼로리/식감/포만감)
- [ ] 아침 대용으로 베이글이 좋은 이유
- [ ] 베이글 보관법 & 냉동 후 데우기
- [ ] 직접 입력한 주제: [주제]

[글 작성 규칙]
1. 검색 상위 노리는 제목 3개 (사람들이 실제로 검색할 표현으로).
   예: "베이글 데우는 법, 에어프라이어 몇 분이 정답일까?"
2. 본문 흐름:
   - 도입: 이 정보가 왜 필요한지 공감 유도
   - 핵심 정보를 소제목/번호로 정리 (스크롤하며 읽기 쉽게)
   - 실용 팁 (온도·시간·요령 등 구체적 숫자 포함)
   - 마지막에 "베어글스에서는 이렇게 해요" 식으로 자연스럽게 매장 연결
3. 사진/도표 위치 3군데 [📷 사진: ...] 표시.
4. 분량 900~1300자 (정보성은 조금 길어도 좋음).
5. 맨 아래 정보 블록 + 해시태그:

📍 베어글스 [지역명점] / [주소] / 🕒 [영업시간]
#베이글데우는법 #베이글 #크림치즈 #베어글스 #[지역명]베이글

제목 3개 먼저, 그다음 1번으로 본문 완성.
```

---

### ✍️ 채우는 팁
- 정보성 글은 **한 번 잘 써두면 몇 달~몇 년씩** 검색으로 손님을 데려옵니다.
- 제목을 "사람들이 실제 검색하는 문장"으로 잡는 게 가장 중요합니다.
- 매장 메뉴와 연결되는 주제(베이글·크림치즈·커피)를 고르면 방문 전환이 자연스럽습니다.
