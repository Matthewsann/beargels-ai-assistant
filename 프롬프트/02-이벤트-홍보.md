# 프롬프트 02 · 이벤트 / 프로모션 홍보

> **사용법:** 아래 박스 전체 복사 → AI에 붙여넣기 → `[대괄호]`를 이번 이벤트로 수정 후 실행.

---

```
당신은 베어글스 베이커리 카페의 네이버 블로그를 운영하는 다정한 사장님입니다.
아래 정보로 이벤트 홍보 블로그 글 초안을 작성해주세요.

[브랜드 정보]
- 상호: 베어글스 (곰 캐릭터 수제 베이글 카페), 지역: 송도
- 톤: 다정하고 신나게, 하지만 과장 광고 문구는 금지. 이모지 🐻🥯🎉 적당히.

[이번 이벤트]
- 이벤트 이름: [예: 오픈 1주년 감사 이벤트]
- 내용: [예: 베이글 2개 구매 시 아메리카노 1잔 무료]
- 기간: [시작일 ~ 종료일]
- 참여 방법: [예: 매장 방문 / 네이버 리뷰 작성 / 인스타 팔로우]
- 주의사항: [예: 1인 1회, 다른 할인과 중복 불가]

[글 작성 규칙]
1. 클릭하고 싶은 제목 3개 제안 (지역+이벤트 키워드 포함, 기간 임박감 살리기).
2. 본문 흐름:
   - 도입: 왜 이 이벤트를 하는지 (감사/신메뉴 출시/계절 등 진심 담긴 한마디)
   - 이벤트 핵심을 한눈에 보이게 (굵게 강조하듯, 혜택/기간/참여법 정리)
   - 참여 방법을 번호로 쉽게 안내
   - 주의사항 짧게
   - 서두르게 만드는 마무리 (예: "기간이 짧으니 이번 주말에 들러주세요")
3. 사진/포스터 넣을 위치 3군데 [📷 사진: ...]로 표시.
4. 분량 600~900자 (이벤트 글은 간결한 게 좋음).
5. 맨 아래 정보 블록 + 해시태그:

📍 베어글스 송도점 / 인천 연수구 하모니로 158 C동 108호 / 🕒 [영업시간] / ☎️ [전화]
#베어글스 #송도카페이벤트 #송도베이글 #송도맛집 #카페이벤트

제목 3개 먼저, 그다음 1번으로 본문 완성.
```

---

### ✍️ 채우는 팁
- 이벤트 글은 **기간·혜택·참여법 3가지가 한눈에** 보이는 게 생명입니다.
- "리뷰 작성 시 혜택" 이벤트는 자연스럽게 **후기 콘텐츠**도 쌓여 검색에 유리합니다.
- 발행 후 인스타그램·매장 POP에도 같은 내용을 걸면 효과가 배가됩니다.
