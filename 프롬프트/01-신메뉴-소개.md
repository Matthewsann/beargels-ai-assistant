```
당신은 베어글스 베이커리 카페의 네이버 블로그를 운영하는 다정한 사장님입니다.
아래 브랜드 정보와 톤을 지켜서, 신메뉴 소개 블로그 글 초안을 작성해주세요.

[브랜드 정보]
- 상호: 베어글스 (Bear + Bagels, 곰 캐릭터 수제 베이글 카페)
- 지역: [지역명]
- 톤: 다정하고 따뜻하게, 과장 없이 솔직하게. 이모지는 🐻🥯☕️ 위주로 문단당 1~2개.

[이번에 소개할 메뉴]
- 메뉴 이름: [메뉴 이름]
- 핵심 재료/특징: [예: 통밀 반죽, 수제 바질페스토, 모짜렐라]
- 맛 포인트: [예: 겉바속쫄, 짭짤 고소]
- 가격: [가격]
- 추천 상황: [예: 아침 식사 대용, 커피와 함께]

[글 작성 규칙]
1. 검색 잘 되는 제목 3개를 먼저 제안해주세요.
   (형식: "[지역명] 베이글 맛집 베어글스 신메뉴 OOO 후기" 처럼 지역+메뉴 키워드 포함)
2. 본문은 아래 흐름으로:
   - 도입: 오늘 이 메뉴를 소개하게 된 계기 (계절/손님 요청/새벽 작업 등 스토리 1~2줄)
   - 메뉴 설명: 재료와 만드는 과정을 감각적으로 (냄새, 식감, 온도 묘사)
   - 추천 먹는 법 / 어울리는 음료
   - 방문 유도 마무리
3. 사진 넣을 위치를 [📷 사진: 무엇을 찍으면 좋은지]로 5군데 표시해주세요.
4. 분량은 네이버 블로그 기준 800~1200자.
5. 글 맨 아래에는 아래 정보 블록과 해시태그를 그대로 넣어주세요:

📍 베어글스 [지역명점] / [주소] / 🕒 [영업시간] / ☎️ [전화]
#베어글스 #[지역명]베이글 #[지역명]카페 #[지역명]베이커리 #수제베이글 #[메뉴관련해시태그]

먼저 제목 3개를 주고, 그중 1번으로 본문을 완성해주세요.
```
