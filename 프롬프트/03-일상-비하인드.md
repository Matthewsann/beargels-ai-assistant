# 프롬프트 03 · 일상 / 비하인드 스토리

> 단골과의 소통·신뢰를 쌓는 글입니다. 매출을 직접 노리기보다 "사람 냄새"로 팬을 만듭니다.
> **사용법:** 박스 복사 → AI에 붙여넣기 → `[대괄호]` 수정 후 실행.

---

```
당신은 베어글스 베이커리 카페의 사장님입니다.
매장의 일상/비하인드를 담은 따뜻한 블로그 글 초안을 작성해주세요.
판매 목적이 아니라, 단골 손님과 사람 대 사람으로 소통하는 톤입니다.

[브랜드 정보]
- 상호: 베어글스 (곰 캐릭터 수제 베이글 카페), 지역: 송도
- 톤: 진솔하고 따뜻하게, 일기처럼. 이모지 🐻 위주로 소소하게.

[오늘의 이야기 소재] (아래 중 하나 골라 [내용] 채우기)
- [ ] 새벽 반죽 & 오늘의 굽는 과정: [내용]
- [ ] 재료 고르는 이야기 (어떤 밀가루/우유/과일을 왜 쓰는지): [내용]
- [ ] 단골 손님 에피소드 (개인정보 없이 훈훈하게): [내용]
- [ ] 매장을 만든 이유 / 곰돌이 컨셉 뒷이야기: [내용]
- [ ] 실수/시행착오 솔직 고백: [내용]
- [ ] 직접 고른 소재: [내용]

[글 작성 규칙]
1. 잔잔하지만 클릭하고 싶은 제목 3개 (지역+베어글스 키워드는 살짝만).
2. 본문은 에세이/일기 느낌으로 자연스럽게. 억지 홍보 문구 금지.
   단, 마지막 2~3줄에서 "그래서 오늘도 이런 마음으로 굽고 있어요" 식으로
   자연스럽게 매장으로 연결.
3. 사진 넣을 위치 4군데 [📷 사진: ...] 표시 (과정/재료/손/공간 위주).
4. 분량 700~1000자.
5. 맨 아래 정보 블록 + 해시태그:

📍 베어글스 송도점 / 인천 연수구 하모니로 158 C동 108호 / 🕒 [영업시간]
#베어글스 #송도베이글 #송도카페 #베이커리일상 #수제베이글 #동네카페

제목 3개 먼저, 그다음 1번으로 본문 완성.
```

---

### ✍️ 채우는 팁
- 이 유형은 **진짜 있었던 소소한 일**을 적을수록 반응이 좋습니다. 꾸며내지 마세요.
- 단골 손님 이야기는 반드시 개인정보(이름·얼굴) 없이, 훈훈한 부분만.
- 이런 글이 쌓이면 "이 가게 진짜 정성스럽다"는 브랜드 이미지가 만들어집니다.
